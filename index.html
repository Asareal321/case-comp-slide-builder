What it does

Built for the way case competitions are judged: one clear message per slide, and every element backs it up.

Asks, then builds

It asks one or two questions at a time, so you never get a wall of questions. Then it researches and fills in the gaps.

Never invents numbers

Figures it hasn't confirmed get flagged with [verify] until you source them. The case prompt is always the source of truth.

Distinctive by default

Layouts are designed to stand out to a judge who has already seen 15 other decks, with fonts and colors matched to the client's brand.

Install it

Choose where you use Claude.

  1. Download the zip

    Use the button above. Don't unzip it. Claude wants the .zip file itself.

  2. Open Settings → Capabilities

    In Claude.ai or the desktop app, click your name (bottom left), then Settings. Make sure Code execution and file creation is turned on. Skills need it to build PowerPoint files.

  3. Upload the skill

    Scroll down to Skills, click Upload skill, and choose case-comp-slide-builder.zip.

  4. Turn it on

    Check that the toggle next to case-comp-slide-builder is on. That's it.

On a Team or Enterprise plan? An admin may need to enable skills for your organization first.
  1. Download the zip

    Use the button above.

  2. Unzip it into your skills folder

    Run this in Terminal from the folder where you downloaded the file:

    mkdir -p ~/.claude/skills && unzip case-comp-slide-builder.zip -d ~/.claude/skills/
  3. Restart Claude Code

    The skill should now show up as /case-comp-slide-builder.

How to use it

Start a new chat and either upload your case prompt (PDF or doc) or describe the slide you need. Claude loads the skill on its own when it sees the request. Try:

"Here's our case prompt. Build me the executive summary slide."
"I need a situational analysis slide for a Canadian Tire case on e-commerce growth."
"Use the case comp slide builder to turn this recommendation into a full deck."
Tip: Answer its questions as you go. It's built to ask only one or two at a time, and the slides get noticeably better with your answers.

FAQ

Is it free?

Yes. You need a Claude plan that supports skills: Pro, Max, Team or Enterprise on Claude.ai, or Claude Code.

The upload says the file is invalid.

Upload the .zip as-is. If your computer unzipped it automatically (Safari does this), compress the case-comp-slide-builder folder again: right-click it and choose Compress.

Claude isn't using the skill.

Make sure the toggle is on under Settings → Capabilities → Skills, and start a new chat. You can also ask for it by name: "use the case comp slide builder."
