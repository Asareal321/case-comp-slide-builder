Install

Up and running in two minutes.

Choose where you use Claude.

  1. Download the zip

    Use the download button. Don't unzip it. Claude wants the .zip file itself.

  2. Open Settings

    Click your name (bottom left), go to Settings → Capabilities, and turn on Code execution and file creation.

  3. Upload the skill

    Under Skills, click Upload skill and choose case-comp-slide-builder.zip.

  4. Switch it on

    Make sure the toggle next to the skill is on. Then start a new chat.

💡Team or Enterprise plan? An admin may need to enable skills for your organization first.
  1. Download the zip

    Use the download button.

  2. Unzip into your skills folder

    Run this in Terminal from the folder where the download is:

    mkdir -p ~/.claude/skills && unzip case-comp-slide-builder.zip -d ~/.claude/skills/
  3. Restart Claude Code

    It shows up as /case-comp-slide-builder.

FAQ

Good questions.

Is it free?

Yes. You need a Claude plan that supports skills: Pro, Max, Team or Enterprise on Claude.ai, or Claude Code.

The upload says the file is invalid.

Upload the .zip as-is. If your computer unzipped it automatically (Safari does this), right-click the case-comp-slide-builder folder and choose Compress, then upload that file.

Claude isn't using the skill.

Check that the toggle is on under Settings → Capabilities → Skills, then start a new chat. You can also ask for it by name: "use the case comp slide builder."

Does it make PowerPoint files?

Yes. It builds real, editable slides you can download and keep working on in PowerPoint or Google Slides.
